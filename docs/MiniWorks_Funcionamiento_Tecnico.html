MiniWorks - Plataforma de Miniempleos Universitarios

Documento técnico integral
Aplicación de miniempleos dentro de la ciudad de Loja para estudiantes universitarios.
Versión documental: 26 de noviembre de 2026

Estado actual comprobado: API, MongoDB, Kong y frontend web están operativos; Flutter fue analizado sin errores y el APK release fue generado.

1. Propósito y alcance

MiniWorks conecta estudiantes universitarios con oportunidades laborales cortas, prácticas o temporales dentro de Loja. Permite que los empleadores publiquen ofertas y revisen postulantes, mientras los estudiantes buscan empleos, postulan y consultan su historial.

UsuarioFunciones principales
EstudianteRegistro, inicio de sesión, búsqueda de empleos, postulación, historial y reseñas.
EmpleadorInicio de sesión, publicación de empleos, revisión de postulaciones y aceptación de candidatos.
AdministradorInicio de sesión y consulta de usuarios registrados.

2.1 Arquitectura lógica

El proyecto usa un monolito modular. No existen actualmente microservicios separados para autenticación, empleos y postulaciones, pero el código está dividido por módulos y puede extraerse hacia servicios independientes en AWS.

→

17. Operación en Amazon para móviles

Para Android: instalar el APK en desarrollo, subirlo a Google Play Console en producción y usar API HTTPS. Para iOS: compilar con macOS, certificados Apple y distribución App Store. El APK actual no es apto para distribución pública hasta firmarlo con una clave propia y configurar el dominio productivo.
